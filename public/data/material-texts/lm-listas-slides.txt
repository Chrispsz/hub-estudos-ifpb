 ○ Listas não-ordenadas
 ○ Listas ordenadas
 ○ Listas de definição

Listas

● O elemento HTML <ol> representa uma lista de itens ordenados,
 que são mostrados com uma contagem que os precede, que
 pode ser de qualquer tipo, como numerais, letras, algarismos
 romanos, ou simples símbolos.

Listas

● O elemento HTML <ul> representa uma lista não-ordenada, isto é,
 suas posições, nessa lista, são irrelevantes. São exibidos com um
 marcador que pode ter várias formas, como um ponto, um círculo, ou
 um quadrado.

Listas
● O elemento HTML <li> é usado para representar um item que faz
 parte de uma lista. Este item deve estar contido em um elemento
 pai: uma lista ordenada (<ol>) ou uma lista não-ordenada (<ul>)

Listas
● As listas de definição servem para criar listas com termos e suas
 deﬁnições.
● A tag <dl> define uma lista de descrição e é utilizada em conjunto
 com a tag <dt> (para definir termos) e <dd> (para descrever cada
 termo).
